# program kasir
Program yang dibuat untuk mempermudah penjualan dengan mencatat, memproses, dan menghitung transaksi penjualan dengan akurat dan efisien, serta mencetak struk untuk pelanggan. Memiliki fitur untuk mencetak struk pembelian dengan tanggal yang tepat, serta fitur untuk mengedit atau menambah stok, dan fitur untuk melihat history pembayaran.
